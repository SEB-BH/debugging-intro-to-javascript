  <span class="subhead">Setup</span>
</h1>

**Learning objective:** Run an existing JavaScript file and use its error messages to start debugging.

1. Download and unzip the starter project provided by your instructor.
2. Open the project folder in VS Code.
3. Open the terminal in VS Code (**Terminal → New Terminal**).
4. Run:

```bash
node app.js
```

You should see an error at first. **That is expected!** The code is intentionally broken.

> 💡 Students on Windows can use Git Bash. Students on Mac can use Terminal or zsh. You do not need `npm install` or a database.

Continue to the [Debugging Challenge](../challenge/README.md).
